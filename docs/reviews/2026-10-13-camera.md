# Camera gateway review

An independent agent reviewed fixed upstream routing, source/session validation,
HLS rewriting, continuous media delivery, cancellation, UI lifecycle, discovery,
and deployment settings. Re-review approved without outstanding blockers.

Resolved findings:

- Effect interruption now cancels upstream work independently of browser abort.
- Rotated video uses swapped dimensions so the frame fits without cropping.
- Narrow controls wrap; autoplay denial offers direct user-gesture playback.
- Compose forwards camera configuration to the backend.
- Continuous media retains active slots/controllers after returning Response,
  honors backpressure, bounds chunks, and renews inactivity deadlines.
- Clean upstream EOF triggers reconnect rather than leaving a stale Live badge.

Real-source testing found that the owner's main H.264 stream failed Chromium's
native MP4/HLS parsing. MediaSource successfully played go2rtc's output. Perilune's
same-origin HTTP-to-MediaSource path then decoded the actual main video, and its
JPEG snapshot endpoint returned successfully. No camera/printer configuration was
changed; physical printer controls remained disabled. No private footage, upstream
addresses, credentials, or configuration are included in this record.

The reviewer independently ran all 29 camera-service tests. Full validation covers
78 domain/component tests, simulator and live-protocol production smoke, and a
synthetic encoded-camera production smoke. The latter proves two viewers, H.264
video decoding, same-origin requests, capture, configuration changes, old-session
invalidation, orientation, preserved drafts, clean EOF/recovery, a 320px mobile
layout, and pause/resume. Fixture desktop/mobile screenshots were inspected.
T3 preview reported no automation host on navigation/open; headless Playwright
provided the final rendered checks. Safari hardware/native-HLS fallback remains
unverified and is recorded as a limitation.
