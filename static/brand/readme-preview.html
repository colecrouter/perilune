Perilune

Your printer, in orbit.
A reliable, thoughtfully designed control interface for Klipper printers.

Perilune is in early development. It places persistent Moonraker connectivity, shared printer state, action tracking, and authenticated camera access behind a self-hosted backend. The browser presents clear progress and reconnecting states without throwing away inputs.

Run locally

Requires Node.js 24.13+ and pnpm 12.11.2. Vite+ is installed locally.
